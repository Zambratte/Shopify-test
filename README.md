# North & Hearth – Shopify Theme

Responsives Shopify-2.0-Theme für hochwertige Outdoor- und Home-Produkte.

## Installation

1. Die Datei `north-and-hearth-shopify.zip` in Shopify unter **Onlineshop → Themes → Theme hinzufügen → ZIP-Datei hochladen** auswählen.
2. Nach dem Upload im Theme-Editor ein Hero-Bild, Menüs und eine Kollektion zuweisen.
3. Das Theme zuerst als Vorschau öffnen und erst nach der Inhaltsprüfung veröffentlichen.

## Empfohlene Einrichtung

- Produktbilder mit mindestens 1800 Pixeln Breite verwenden.
- Kollektionen wie Outdoor Living, Fire & Light, Furniture und Home Retreat anlegen.
- Seiten für Über uns, Lieferung, Rückgabe, Garantie und Kontakt erstellen.
- Shopify Payments, Versandprofile, Markets und Rechtstexte vor der Veröffentlichung konfigurieren.

Das Theme enthält keine Produkte, Preise, Zahlungsanbieter oder Rechtstexte. Diese Inhalte werden im Shopify-Admin gepflegt.
