# North & Hearth – Shopify Theme

Premium Shopify-2.0-Theme für hochwertige Outdoor- und Home-Produkte.

## Installation

1. Dieses Repository zu GitHub pushen.
2. In Shopify: **Onlineshop → Themes → Theme hinzufügen → Von GitHub verbinden**.
3. Repository und Branch auswählen.
4. Im Theme Editor Hero-Bild, Menüs, Kollektionen und Texte zuweisen.

## Empfohlene Einrichtung

- Produkte ab 300 USD mit hochwertigen Bildern (mindestens 1800 px)
- Kollektionen: Outdoor Living, Fire & Light, Furniture, Home Retreat
- Seiten: Über uns, Lieferung, Rückgabe, Garantie, Kontakt/Produktberatung
- Shopify Payments, Versandprofile und Markets vor Veröffentlichung konfigurieren

Das Theme enthält keine Produkte, Preise, Zahlungsanbieter oder Rechtstexte; diese werden im Shopify Admin gepflegt.
